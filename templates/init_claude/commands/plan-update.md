# 実装計画の更新

対象ファイル: plans/plan.md
追加メモ: $ARGUMENTS

## 手順
### 1. 会話から拾う
直前の /plan-review 以降の会話全体と、上の追加メモから次を拾う。
- 私の回答で決まったこと → 「決定事項」
- 私が追加した仕様 → 該当するセクション
- 結論が出なかったこと・新たに生じた疑問 → 「未決事項・質問」
- 決まったことに対応する未決事項 → 削除

検討中の案や、私が迷っているだけの発言は決定事項にしないこと。

### 2. 反映前に確認する
ファイルを変更する前に、次の形で差分を見せて、私の OK を待つ。
- 追加: （セクション名）内容
- 変更: （セクション名）変更前 → 変更後
- 削除: （セクション名）内容
- 矛盾・懸念: あれば

### 3. 反映する
OK が出たら plans/plan.md を更新し、「変更履歴」に日付と要約を1行追記する。

### 4. 報告
残っている未決事項だけを番号付きで一覧にする。
未決事項が0件なら「/plan-finalize に進めます」と伝える。

## ファイルが無い場合
plans/plan.md が存在しなければ、次の構成で新規作成してから反映する。

```
# 目的
# 決定事項
# 未決事項・質問
# 実装方針
# 変更履歴
```
