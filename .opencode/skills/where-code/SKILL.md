---

`$ARGUMENTS` について調べて報告してください。

## 報告内容
1. **定義**：ファイル:行番号
2. **概要**：何をするものか1文で、型や引数・戻り値の要約
3. **使用箇所**：ファイル:行番号の一覧（20件を超える場合はファイルごとの件数にまとめる）
4. **直近の変更**：`git log -S "$ARGUMENTS" -3 --oneline` で、このシンボルに関わる直近3件のコミット

## ルール
- Grep と Glob で効率よく調べ、Read は定義部分の確認など最小限にする
- 同名の定義が複数ある場合は、それぞれ分けて報告する
- 見つからない場合は、似た名前の候補を挙げる
- コードの変更はしない
